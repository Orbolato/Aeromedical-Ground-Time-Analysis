# Data access

The raw and mission-level datasets used in the associated study are **not included in this repository**.

The source data are maintained by the **Brazilian Air Force (FAB) / Aerospace Operations Command (COMAE)** and are subject to operational-security restrictions. Full reproduction of the analysis from source records therefore requires institutional authorization and access through the applicable FAB/COMAE procedures.

This repository is intended to provide:

- the published analysis code;
- the aggregate supplementary output tables released with the article; and
- documentation sufficient to understand the analytical workflow and software environment.

No restricted mission-level records, identifiers, routes, timestamps, or other non-public operational data should be committed to this repository.

For the formal data-availability statement, see the Version of Record:

https://doi.org/10.3390/sci8070169
