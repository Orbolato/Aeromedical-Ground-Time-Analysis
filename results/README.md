# Published aggregate results

This directory is reserved for the aggregate output tables distributed with the published article's supplementary material.

The underlying mission-level Brazilian Air Force (FAB) / Aerospace Operations Command (COMAE) data are **not** distributed in this repository because they are subject to operational-security restrictions.

## Published tables

The MDPI supplementary package identifies the following aggregate CSV files:

1. `audit_counts.csv` — record-to-mission audit counts.
2. `mission_descriptive_by_modality.csv` — mission-level descriptive statistics by procurement modality.
3. `mission_descriptive_by_organ_profile.csv` — organ-profile summaries.
4. `model_comparison_grouped_likelihood.csv` — grouped-likelihood model comparison.
5. `bootstrap_percentile_summary.csv` — refitted-bootstrap percentile summaries.
6. `threshold_sensitivity.csv` — threshold-exceedance probabilities.
7. `quarterly_temporal_summary.csv` — quarterly temporal summaries.
8. `temporal_trend_screen.csv` — Spearman temporal-trend screen.
9. `chronological_validation_2025.csv` — chronological-validation results.

The authoritative published supplementary package is available at:

https://www.mdpi.com/article/10.3390/sci8070169/s1

Once the exact published CSV files are mirrored here, they should be kept unchanged so that this directory remains traceable to the Version of Record.
